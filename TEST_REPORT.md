## Покрытие реальной среды

Тесты PostgreSQL работают на имитаторе SQL-обращений и файловой сериализации PTB;
это **не** интеграционные тесты с настоящим PostgreSQL, драйвером psycopg,
реальной сетью, Telegram API или пользовательским хостингом.
`tests_runtime.py` не запускался здесь, поскольку python-telegram-bot не установлен;
его можно выполнить в рабочем виртуальном окружении пользователя.

**Важно:** ни один реальный пользовательский БД-снимок не изучался и не изменялся.
Для диагностики реальной БД запусти `python db_recovery.py` и проверь список
строк до любого восстановления.
